개인정보 처리방침

시행일 2026년 10월 13일

mmnt는 계정이 없고, 이름이나 이메일 같은 개인 정보를 요구하지 않습니다. 여러분이 쓴 글은 기기 안에만 저장되며 어떤 형태로도 서버에 전송되지 않습니다. 앱이 바깥으로 보내는 것은 설정에서 끌 수 있는 익명 사용 통계와 오류 리포트, 그리고 새 버전 확인 요청뿐입니다.

1. 글과 설정

작성한 글, 작성 이력과 통계, 앱 설정은 모두 사용자의 기기 안에 있는 로컬 데이터베이스에 저장됩니다. 이 데이터는 사용자의 기기를 떠나지 않습니다. 완료된 글은 설정한 보관 기간(기본 30일)이 지나면 기기에서 영구 삭제되며, 사용자가 영구 보관으로 표시한 글만 남습니다. 앱을 삭제하면 이 데이터도 함께 삭제됩니다.

2. 익명 사용 통계

어떤 기능이 얼마나 쓰이는지 파악하기 위해 익명 사용 통계를 보냅니다. 이 기능은 기본으로 켜져 있으며, 설정의 "익명 사용 통계 보내기"를 끄면 즉시 중단됩니다. 끈 뒤에는 아무 데이터도 만들지도, 쌓아 두지도 않습니다.

보내는 항목은 다음이 전부입니다.

설치 ID최초 실행 때 만든 무작위 값입니다. 사용자나 기기를 알아볼 수 없으며, 앱을 삭제하고 다시 설치하면 새 값이 됩니다.
앱 버전, 플랫폼예: 0.1.0, macos
운영체제 주 버전예: 26. 세부 버전은 보내지 않습니다.
사용 이벤트앱 실행, 글쓰기 시작과 완료, 설정 변경 같은 동작의 종류입니다.
구간값글 길이와 작성 시간은 정확한 값 대신 "50~149 단어", "3~5분" 같은 구간으로만 보냅니다.

글의 본문이나 일부, 정확한 글자 수와 단어 수, 이름, 이메일, 기기 이름, 언어 설정, 위치는 보내지 않습니다. 통계는 PostHog(EU 서버)에 저장되며, 개인별 프로필을 만들지 않고 IP 주소는 수신 즉시 폐기하도록 설정되어 있습니다.

3. 처리 위탁과 국외 이전

위 통계와 오류 리포트의 저장과 분석은 PostHog에 맡기며, 데이터는 국외 서버에 보관됩니다. 설정에서 "익명 사용 통계 보내기"를 끄면 이 이전도 함께 중단됩니다.

4. 오류 리포트

앱 안에서 처리되지 않은 오류가 생기면 오류의 종류, 메시지, 그리고 어느 코드에서 났는지 알려 주는 스택 추적 정보를 위 통계와 같은 경로로 보냅니다. 메시지에 포함될 수 있는 홈 폴더 경로는 가린 뒤 보내며, 글 내용은 포함되지 않습니다. "익명 사용 통계 보내기"를 끄면 오류 리포트도 함께 꺼집니다.

5. 새 버전 확인

앱은 시작할 때, 그리고 설정에서 직접 확인할 때 GitHub에 올려 둔 버전 정보 파일을 내려받습니다. 이 요청에는 앱이 추가하는 정보가 없지만, 일반적인 인터넷 접속과 마찬가지로 GitHub가 IP 주소 같은 접속 기록을 남길 수 있습니다. 이에 대해서는 GitHub 개인정보 보호 정책이 적용됩니다.

6. 이 웹사이트

이 사이트는 GitHub Pages로 제공되며, 방문자 분석 도구나 쿠키를 사용하지 않습니다. 다운로드 버튼의 버전 표시는 GitHub에 있는 버전 정보 파일을 읽어 채우므로, 이때도 위와 같은 GitHub 접속 기록이 남을 수 있습니다.

7. 수집하지 않는 것

  • 계정, 이름, 이메일 주소, 전화번호
  • 글의 본문과 그로부터 계산한 원시 값
  • 기기 이름, 정밀한 운영체제 버전, 언어와 지역 설정
  • 위치 정보, 연락처, 다른 앱의 데이터

8. 보관과 삭제

익명 통계는 사용자와 연결할 수 있는 정보를 담고 있지 않으므로, 특정 사용자의 데이터만 골라 삭제하는 것은 불가능합니다. 더 이상 보내고 싶지 않다면 설정에서 끄면 되고, 앱을 삭제하면 설치 ID가 사라져 이후 데이터와 이어지지 않습니다.

9. 이용 조건

mmnt는 동작이나 품질을 보증하지 않습니다. 글은 설계상 보관 기간이 지나면 삭제되므로, 남겨야 할 글은 영구 보관으로 표시하거나 따로 복사해 두시기 바랍니다. 소프트웨어 오류나 기기 문제로 생긴 글의 손실을 포함해, 앱 사용으로 발생한 손해에 대해 개발자는 책임을 지지 않습니다.
